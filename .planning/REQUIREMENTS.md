# Requirements

- [x] LAB-01: Start/stop camera; visible face mesh, iris detail, head pose, quality and timing.
- [x] LAB-02: Estimated distance with stated assumptions; adjustable IPD/FOV and intrinsics tool.
- [x] CAL-01: Randomized repeated calibration with settling, fixation quality and skip/cancel.
- [x] CAL-02: Grouped model selection, profile save/load and camera/screen compatibility checks.
- [x] VAL-01: Independent unseen targets; pixel errors, angular estimate, precision and dropout.
- [x] PTR-01: Preview and explicit native mouse arming; emergency stop and loss-of-tracking freeze.
- [x] DATA-01: Export raw numeric samples and full reproducible session report; no video persistence.
- [x] RUN-01: Install/launch instructions and runtime verification with bounded evidence.

All requirements map to Phase 01. Feature implementation is verified; personal gaze accuracy and
measured chessboard optics require the user's participation and are not claimed as completed experiments.
